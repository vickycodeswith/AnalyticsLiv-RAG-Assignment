# Sample data

All data in this folder is fictional and was created for the AnalyticsLiv RAG assignment.

- `novatech.db`: ready-to-use SQLite database.
- `schema.sql`: database schema.
- `novatech_dump.sql`: schema and insert statements to recreate the database.
- `documents/`: six mixed-format business documents (PDF, DOCX, TXT).

The database contains 60 projects, 100 employees, and 150 support tickets. Foreign keys connect employees to projects and support tickets to employees.
